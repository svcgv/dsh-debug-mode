# ADR 0002：统一 DebugRun 与三个模型工具

- 状态：Accepted
- 日期：2026-09-04

## 背景

前端埋点和后端断点使用不同底层机制，但都需要目标定位、运行资源、等待复现、证据读取和安全结束。如果把每个内部步骤暴露为工具，模型接口会与实现复杂度等大，难以保持正确调用顺序。

## 决策

每个 Session 最多拥有一个 `DebugRun`，由 `DebugRunManager` 管理。模型只使用三个稳定工具：

- `debug_start`
- `debug_control`
- `debug_finish`

语言、框架、协议和操作系统差异由内部 Adapter 处理。工具在 Debug 开关前后保持注册，非 Debug 状态下由执行器拒绝。

## 影响

- 模型学习的接口小，复杂生命周期集中在一个模块。
- 前后端事件可以共享游标、等待和有界读取约定。
- 单次运行不能混合前后端目标；跨端问题需要顺序建立两个运行。
- 新增语言或调试器只增加 Adapter，不增加模型工具。
