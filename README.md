# dsh-debug-mode

DeepSeek Harness 的 Debug Mode Bundle，目标是在 Web composer 中提供 Normal、Plan、Debug 模式，并通过运行时埋点或后端调试器帮助 agent 获取可验证的故障证据。

## 当前状态

阶段一工程规范和质量门禁已经完成并通过本地验证，当前等待人工确认。Debug Mode 业务功能尚未实现。
